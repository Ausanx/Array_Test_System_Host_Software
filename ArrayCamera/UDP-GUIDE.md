# Array Test System - UDP 通信调试工具 v1.1

## 🎉 新增功能

### 1. 健壮的日志系统

- **位置**: 窗口底部（200px 高度）
- **颜色编码**:
  - ⚪ **Info**: 白色 - 普通信息
  - 🟢 **Success**: 绿色 - 操作成功
  - 🟡 **Warning**: 黄色 - 警告信息
  - 🔴 **Error**: 红色 - 错误信息
- **时间戳**: 每条日志自动添加 `[HH:mm:ss.fff]`
- **线程安全**: 使用 `Dispatcher.Invoke` 确保从网络线程调用安全
- **自动滚动**: 新日志自动滚动到底部

### 2. UDP 网络通信

- **目标 IP**: `192.168.2.88` (可配置)
- **控制端口**: `8080` (可配置)
- **本地端口**: `8081` (固定)

### 3. 指令调试面板

支持发送标准 32 字节控制指令：

| CmdID | 功能             | 说明           |
| ----- | ---------------- | -------------- |
| 1     | 复位 (Reset)     | 重启 FPGA 系统 |
| 2     | 配置 (Config)    | 配置参数       |
| 3     | 开始采集 (Start) | 启动数据采集   |
| 4     | 停止采集 (Stop)  | 停止数据采集   |

## 📦 指令格式

```csharp
struct CommandPacket (32 bytes)
{
    uint Header;      // 0x55AAAA55 (固定)
    byte CmdID;       // 指令ID (1-4)
    byte Mode;        // 模式 (默认0)
    ushort Reserved1; // 保留
    uint Param1;      // 参数1
    uint Param2;      // 参数2
    byte[16] Reserved2; // 保留字段
}
```

## 🚀 使用指南

### 步骤 1: 绑定 UDP 连接

1. 在"连接设置"中输入目标 IP（默认 `192.168.2.88`）
2. 输入控制端口（默认 `8080`）
3. 点击 **"绑定/重置连接"** 按钮
4. 查看日志窗口确认连接状态：
   - ✅ 绿色：`UDP连接已初始化 → 192.168.2.88:8080 (本地端口: 8081)`
   - ❌ 红色：`网络异常: ...` 或 `IP地址格式错误`

### 步骤 2: 发送调试指令

1. 在"指令调试"面板选择 **CmdID**
2. 输入 **Param1** 和 **Param2**（整数）
3. 点击 **"📤 发送指令"**
4. 日志窗口显示：
   - 成功：`✓ 已发送指令: ID=3, Param1=100, Param2=200 (32 bytes)`
   - 失败：`发送失败: 网络不可达` 或 `提示: 网络不可达，请检查IP地址和网络连接`

### 步骤 3: 快捷复位

点击 **"复位FPGA"** 按钮，等效于发送 `CmdID=1, Param1=0, Param2=0`

## ⚠️ 异常处理

### 1. IP 格式错误

```
[13:25:42.156] IP地址格式错误: 192.168.2  (红色)
```

**解决**: 检查 IP 格式，必须为标准 IPv4 格式（如 `192.168.2.88`）

### 2. 端口被占用

```
[13:26:15.234] 网络异常: 通常每个套接字地址(协议/网络地址/端口)只允许使用一次 (ErrorCode: 10048)  (红色)
```

**解决**:

- 关闭其他占用 8081 端口的程序
- 或修改代码中的 `LocalPort` 常量

### 3. 网络不可达

```
[13:27:30.567] 发送失败: 网络不可达 (ErrorCode: 10051)  (红色)
[13:27:30.568] 提示: 网络不可达，请检查IP地址和网络连接  (黄色)
```

**解决**:

- 检查 FPGA 板卡是否开机
- 检查网线连接
- 使用 `ping 192.168.2.88` 测试连通性
- 确认电脑和 FPGA 在同一网段

### 4. 参数格式错误

```
[13:28:10.234] Param1 格式错误，必须为整数  (黄色)
```

**解决**: 确保 Param1 和 Param2 输入框中只包含整数（0-4294967295）
