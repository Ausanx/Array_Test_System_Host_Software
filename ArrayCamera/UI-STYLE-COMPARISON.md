# UI 风格对比

## ✅ 已应用 WinForms 项目风格

### 颜色方案

| 元素           | 颜色值    | 说明                                                    |
| -------------- | --------- | ------------------------------------------------------- |
| **背景色**     | `#F0F2F5` | 浅灰蓝背景（WinForms: `Color.FromArgb(240, 242, 245)`） |
| **控制面板**   | `#FFFFFF` | 纯白表面                                                |
| **热力图区域** | `#0F172A` | 深色背景（保持一致）                                    |
| **输入框背景** | `#F8FAFC` | 浅灰输入框                                              |
| **边框**       | `#E2E8F0` | 浅色边框                                                |

### 按钮配色（完全匹配 WinForms）

| 按钮类型      | 颜色      | 使用场景           |
| ------------- | --------- | ------------------ |
| **成功/连接** | `#22C55E` | 连接按钮           |
| **危险/断开** | `#EF4444` | 断开、停止按钮     |
| **主要/开始** | `#3B82F6` | 开始采集按钮       |
| **中性/复位** | `#64748B` | 复位、停止演示按钮 |
| **警告/演示** | `#F97316` | 启动演示按钮       |

### 文字颜色

| 元素         | 颜色      | 说明           |
| ------------ | --------- | -------------- |
| **主要文字** | `#1E293B` | 标题、按钮文字 |
| **次要文字** | `#475569` | 标签、提示文字 |

### 布局特性

✅ **GroupBox 分组**（与 WinForms 一致）：

- 连接设置
- 采集控制
- 参数设置
- 渲染设置
- 演示模式
- 系统状态

✅ **右侧控制面板**：380px 宽度

✅ **左侧热力图**：深色背景 `#0F172A`，带圆角边框

✅ **字体**：

- 标准：Segoe UI（匹配 WinForms）
- 代码/数字：Consolas
- 中文加粗：Microsoft YaHei UI

### 新增功能（对齐 WinForms）

- ✅ TIA 增益范围选择（4 档）
- ✅ 帧平均滤波（Checkbox + Slider）
- ✅ 自动缩放开关
- ✅ 显示网格选项
- ✅ 丢帧率显示
- ✅ 5 种颜色映射（Jet/Hot/Gray/Viridis/Parula）
