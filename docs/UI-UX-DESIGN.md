# UI/UX 优化文档

## 🎨 设计系统

### 配色方案

本项目采用**专业科学仪器**的配色方案，强调可读性和数据可视化。

#### 主题色（Tailwind-inspired）

```
背景色系:
- 主背景: #F0F2F5 (slate-100)
- 面板背景: #FFFFFF (white)
- 输入框背景: #F8FAFC (slate-50)
- 深色背景: #0F172A (slate-900) - 用于数据可视化区域

文字色系:
- 主文字: #1E293B (slate-800)
- 次要文字: #475569 (slate-600)
- 标签文字: #64748B (slate-500)

功能色:
- 成功/连接: #22C55E (green-500)
- 成功悬停: #16A34A (green-600)
- 危险/断开: #EF4444 (red-500)
- 危险悬停: #DC2626 (red-600)
- 主要操作: #3B82F6 (blue-500)
- 主要悬停: #2563EB (blue-600)
- 中性操作: #64748B (slate-500)
- 中性悬停: #475569 (slate-600)
```

### 字体系统

```
界面字体:
- 标题/分组: Segoe UI Semibold, 9.5pt
- 正文: Segoe UI, 9pt
- 按钮: Segoe UI Semibold, 9.5pt

数据字体:
- IP地址/数字: Consolas, 10pt (等宽)
- 状态栏: Consolas, 9.5pt
- 中文操作: Microsoft YaHei UI, 10.5pt Bold
```

## 🖱️ 交互设计

### 按钮状态

所有操作按钮实现以下状态：

1. **Normal（正常）**
   - 定义的基础颜色
   - 无边框（FlatStyle.Flat）
   - 手型光标（Cursor.Hand）

2. **Hover（悬停）**
   - 颜色加深约20%
   - 平滑过渡效果

3. **Disabled（禁用）**
   - 自动灰度处理
   - 默认光标

### 按钮颜色映射

| 功能     | 正常色    | 悬停色    | 语义      |
| -------- | --------- | --------- | --------- |
| 连接     | `#22C55E` | `#16A34A` | 成功/启动 |
| 断开     | `#EF4444` | `#DC2626` | 危险/停止 |
| 复位     | `#64748B` | `#475569` | 中性操作  |
| 开始采集 | `#3B82F6` | `#2563EB` | 主要操作  |
| 停止采集 | `#EF4444` | `#DC2626` | 危险/停止 |

### 图标符号

为关键操作添加Unicode符号以增强识别：

- `▶` 开始采集（播放）
- `⏹` 停止采集（停止）
- `●` 已连接（实心圆点）
- `○` 未连接（空心圆点）

## 🎨 设计决策依据

### 为什么选择这些颜色？

1. **深色数据可视化背景** (#0F172A)
   - 科学仪器行业标准
   - 减少眼疲劳
   - 突出彩色热力图

2. **白色控制面板** (#FFFFFF)
   - 提高可读性
   - 清晰区分功能区
   - 符合Windows应用习惯

3. **语义化按钮色**
   - 绿色=启动/连接（积极）
   - 红色=停止/断开（警告）
   - 蓝色=主要操作（中性）

### 为什么使用等宽字体？

- IP地址对齐
- 数字易于比较
- 专业技术感

### 为什么添加Unicode符号？

- 提高识别速度
- 减少文字阅读负担
- 国际化友好
