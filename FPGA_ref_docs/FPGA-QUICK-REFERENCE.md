# FPGA UDP 协议快速参考卡片

## 🔌 网络配置

| 项目         | 值                                |
| ------------ | --------------------------------- |
| FPGA IP      | 192.168.2.88                      |
| PC IP        | 192.168.2.100 (或其他192.168.2.x) |
| FPGA监听端口 | 8080 (接收指令)                   |
| 图像发送端口 | 8081 (发送图像)                   |
| 网络类型     | Ethernet (千兆或百兆)             |
| 数据顺序     | Little Endian (Intel格式)         |

---

## 📦 指令包格式 (28字节)

```
偏移   字段        大小    说明                      值
────────────────────────────────────────────────────
0-3    Header      4字节   固定值                    0x55AAAA55
4-7    CmdID       4字节   命令类型 (0-4)           见下表
8-11   Mode        4字节   扫描模式 (0/1)           0=Preview/1=Precision
12-15  Param1      4字节   TIA增益 (0-7)            根据要求
16-19  Param2      4字节   等待周期                 0
20-23  Reserved1   4字节   保留                      0
24-27  Reserved2   4字节   保留                      0
```

### 命令列表

| CmdID | 命令名 | 含义      | 必须回复ACK? | 发送方    |
| ----- | ------ | --------- | ------------ | --------- |
| 0     | PING   | 握手/测试 | **是**       | PC → FPGA |
| 1     | RESET  | 系统复位  | **是**       | PC → FPGA |
| 2     | CONFIG | 配置参数  | **是**       | PC → FPGA |
| 3     | START  | 启动扫描  | **是**       | PC → FPGA |
| 4     | STOP   | 停止扫描  | **是**       | PC → FPGA |

---

## 🖼️ 图像数据包格式 (524字节)

```
偏移    字段        大小    说明
──────────────────────────────────────────
0-3     Magic       4字节   固定值: 0xAA55AA55
4-7     FrameNum    4字节   帧号 (递增)
8-9     RowNum      2字节   行号 (0-511)
10      SegNum      1字节   段号 (0-3)
11      Type        1字节   数据类型 (0)
12-523  PixelData   512字节 128个uint32像素
```

### 关键参数

- **FrameNum**: 从0开始，每完成512行数据递增一次
- **RowNum**: 0-511，每发送128个像素递增（4个SegNum完成）
- **SegNum**: 0-3，512个像素分4个段发送，每段128像素
- **PixelData**: 128个uint32，每个值范围0-10000

### 例子

```
Frame 0, Row 0:
  Seg 0: 像素0-127
  Seg 1: 像素128-255
  Seg 2: 像素256-383
  Seg 3: 像素384-511

Frame 0, Row 1:
  Seg 0: 像素512-639
  ...
```

## ⚡ 关键工作流程

```
1. 初始化
   ├─ 配置IP: 192.168.2.88/24
   ├─ 绑定监听: UDP 0.0.0.0:8080
   ├─ 启动RX线程
   └─ 等待来自PC的连接

2. 握手 (PC发起)
   ├─ PC: 发送CmdID=0(PING)到8080
   ├─ FPGA: 收到Ping → 立即回复同样的28字节到PC:8080
   ├─ PC: 验证ACK包，确认连接
   └─ ✓ 连接建立

3. 运行 (PC启动)
   ├─ PC: 发送CmdID=3(START)到8080
   ├─ FPGA: 收到Start → 回复ACK → 启动扫描
   ├─ FPGA: 开始采集图像数据
   ├─ FPGA: 发送图像包到PC:8081
   └─ PC: 接收并显示图像

4. 停止 (PC发起)
   ├─ PC: 发送CmdID=4(STOP)到8080
   ├─ FPGA: 收到Stop → 回复ACK → 停止扫描
   └─ ✓ 扫描停止
```

## 🧮 数据量计算

```
分辨率:           512 × 512像素
数据类型:         uint32 (4字节/像素)

单帧像素数:       512 × 512 = 262,144像素
单帧数据包数:     262,144 ÷ 128 = 2,048个524字节包
单帧数据量:       2,048 × 524 = 1,073,152字节 ≈ 1MB

目标帧率:         30 FPS
总吞吐量:         1MB × 30 = 30MB/s
网络占用:         30MB/s ÷ 125MB/s(千兆) = 24% ✓
传输延迟:         1MB ÷ 30MB/s ≈ 33ms/帧

单个524字节包的:
  生成延迟:       < 100µs
  传输延迟:       524字节 ÷ 30MB/s ≈ 17µs
  缓冲延迟:       < 1ms
```

## ❌ 常见错误

| 错误       | 原因           | 解决                           |
| ---------- | -------------- | ------------------------------ |
| Header错误 | 字节序不对     | 使用Little Endian (0x55AAAA55) |
| 连接超时   | 没有ACK回复    | 接收Ping后立即发送相同28字节   |
| 数据丢失   | 缓冲区小       | 接收缓冲至少10MB               |
| 帧率低     | 发送太慢       | 异步发送，不要阻塞             |
| 显示错误   | SegNum顺序错误 | 每行必须4个段连续发送          |

### 验证包大小

```
过滤 udp && frame.len == 56   (28字节指令+以太网头)
过滤 udp && frame.len == 552  (524字节图像+以太网头)
```

### Python快速测试

```python
import socket
import struct

# 发送Ping
sock = socket.socket(AF_INET, SOCK_DGRAM)
ping = struct.pack('<7I', 0x55AAAA55, 0, 0, 0, 0, 0, 0)
sock.sendto(ping, ('192.168.2.88', 8080))

# 接收ACK
data, addr = sock.recvfrom(1024)
if len(data) == 28 and struct.unpack('<I', data[:4])[0] == 0x55AAAA55:
    print("✓ 握手成功")
else:
    print("✗ 握手失败")
```
