## ✅ 通信流程验证

### 步骤1：建立连接

```
[PC] → 发送Ping到 192.168.2.88:8080
         Header=0x55AAAA55
         CmdID=0
         共28字节

[FPGA] → 立即收到Ping包
        检查Header和长度
        立即回复相同的28字节到 192.168.2.100:8080
        
[PC] → 收到ACK，RxCount增加
      确认连接成功
      显示 "✓ 握手成功，连接已建立"
```

**测试方法**：
1. 启动FPGA UDP服务
2. 启动C# ArrayCamera
3. 点击"连接/绑定"按钮
4. 查看日志是否显示握手成功

### 步骤2：启动扫描

```
[PC] → 发送Start命令到 192.168.2.88:8080
       Header=0x55AAAA55
       CmdID=3
       Mode参数（预留）
       
[FPGA] → 收到Start，进入扫描模式
        立即回复ACK
        启动ADC采集
        开始发送图像数据包到 192.168.2.100:8081
        
[PC] → 接收第一个524字节图像包
      解析包头，验证Magic=0xAA55AA55
      提取行号、段号、帧号
      显示图像数据
```

**测试方法**：
1. 连接成功后，点击"开始扫描"按钮
2. 观察 PacketCount 是否快速增加
3. 查看图形显示区是否出现波形

### 步骤3：停止扫描

```
[PC] → 发送Stop命令到 192.168.2.88:8080
       CmdID=4
       
[FPGA] → 停止数据发送
        回复ACK
        
[PC] → 显示"未连接"或"已停止"
```

### 指令包 (28字节) - 使用Wireshark验证

```

00 00 00 00       ← Param1 = 0
00 00 00 00       ← Param2 = 0
00 00 00 00       ← Reserved1
00 00 00 00       ← Reserved2
```

```
00 00 00 00       ← FrameNum = 0
00 00             ← RowNum = 0
00                ← SegNum = 0
00                ← Type = 0
[128个uint32的像素数据]
```

## ✅ 性能指标验证

### 网络吞吐量检查

```python
# 理论计算
单帧数据: 512行 × 4段 = 2048包
单包大小: 524字节
单帧大小: 2048 × 524 = 1,073,152 字节 ≈ 1 MB

帧率: 30 FPS
总吞吐量: 1 MB × 30 = 30 MB/s

千兆网: 1000 Mbps = 125 MB/s
充足吗: 30 MB/s < 125 MB/s ✓ (占用24%)
```

### 延迟指标检查

| 指标 | 期望值 | 验证方法 |
|------|--------|--------|
| ACK响应延迟 | < 1ms | Wireshark中Ping→ACK的时间差 |
| 握手总延迟 | < 100ms | C#日志中"连接成功"前的时间 |
| 单帧传输时间 | ~33ms | 1MB ÷ 30MB/s = 33.3ms |
| 单包到达间隔 | < 20µs | 理论: 33.3ms ÷ 2048 ≈ 16.3µs |

## ✅ 错误排查清单

### 情况1：`握手超时 (3000ms)`

**可能原因**：
- [ ] FPGA没有收到Ping包 → 检查网络连接
- [ ] FPGA收到但没有回复 → 检查Echo ACK逻辑
- [ ] FPGA回复到错误的端口 → 确保发送到 8080
- [ ] PC防火墙拦截 → 添加防火墙规则

**排查步骤**：
```bash
# 1. 确认网络通
ping 192.168.2.88

# 2. 使用Wireshark抓包
# - 过滤: udp.port == 8080 or udp.port == 8081
# - 检查是否有Ping包发出
# - 检查是否有回复包

# 3. FPGA端调试
# - 打印接收到的包数据
# - 验证Header是否正确识别
# - 检查ACK是否真的发送了
```

### 情况2：收到部分包但显示不完整

**可能原因**：
- [ ] 网络丢包 → 检查网线质量

- [ ] 路由器/交换机限流

**排查步骤**：
```python

for each image_packet:
    send(packet)
    sent_packets += 1

# 在C#端检查
```
